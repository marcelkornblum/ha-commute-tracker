# Technology Stack

- **Language:** Python 3.14+
- **Framework:** Home Assistant Custom Component ecosystem
- **Package Manager / Environment:** `uv`
- **Testing:** `pytest`, `pytest-asyncio`, `pytest-cov`, `pytest-homeassistant-custom-component`
- **Distribution:** HACS (Home Assistant Community Store) compliance out of the box (`hacs.json`, `info.md`)
- **Frontend:** Lovelace Custom Card (`commute-tracker-card` in Lit/Typescript or raw JS)
- **CI/CD:** GitHub Actions
